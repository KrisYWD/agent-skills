# 阶段二 · 探索

一轮 = 八步。**grill 在每轮末尾，这是整套流程的铰链。**

```
① 生成任务书  →  ② 给用户过目（等确认）  →  ③ 派队  →  ④ 核完整性
                                                            ↓
   ⑧ 判断续否  ←  ⑦ grill 一次  ←  ⑥ 用户读  ←  ⑤ 写 digest + 更新地图
   └─────────────────── 继续则回 ① ───────────────────┘
```

## ① 生成任务书

**每一路从 `unknowns.md` 的「已知的未知」栏长出来**，不是你凭空编的。硬约束：

> **任务书必须写明它对应地图上的哪几条 unknown。写不出对应关系的路不派。**

这比人工审查更机械，也堵死了"品类级宽泛任务"这个失败模式。

### 分路原则

**路多、切口窄。** 每路检索预算 **30-40 次**，不要 70-100。

有实测支持：**77-94% 的检索回合不带来任何新证据**，累计召回在**前五个回合就到约 50%**；错误轨迹比正确轨迹**长 1.9-2.9 倍**——查得越久越可能是在错方向上打转。更刺眼的一条：工具调用从 2 增到 150，**事实准确率平均下降约 42%**，而链接有效性和话题相关性几乎不变。**表面指标全绿，事实在烂。**

### 每路必须预声明充分性条件

派单时就写死"必须拿到什么才算查完"，做成可勾选清单。

> **充分性条件（本路不满足不许收工）**
> - [ ] 至少 3 家可询价供应商的公司名 + 产品页 URL
> - [ ] 至少 1 个带测试条件的良率或节拍数字
> - [ ] 关键专利 2 件以上的号码 + 当前法律状态 + 核验 URL
> - [ ] 「为什么还没普及」有明确答案或明写"未能确证"

消融数据反直觉：**去掉终止判据后，产出可执行性从 82.09 掉到 73.67，同时工具调用从 327 降到 224**——没有充分性条件的 agent 是**提前停**，不是过度搜。

### 常设两路

- **技术坟场** —— 被试过又消失的路线。**产出不是技术清单，是死因清单。** 每条必答：性能不行？成本？量产不了？法规挡住？安全问题？还是只是需求没了？（最后这个死因最重要——技术本身可能是好的，只是生错了时候）
  ⚠️ **"技术坟场"不是术语**，只在博客和咨询内容里作比喻。正式文档里用 **de-adoption / exnovation / discontinuance**。学理依据是 Denrell 的**失败欠采样**：可观察的都是选择过程的幸存者，导致在全样本中无关甚至有害的做法，在幸存者样本里呈现正相关。
- **头部厂家在花钱做什么** —— 专利申请方向、产线投资、收购、**退出**。花钱和撤钱比论文更能说明趋势。政府/军方立项书尤其值得找，那些文件直接写明"现有技术的不足"。

### 成本那一列会全是"未能确证"

价格不在论文里。**有效的公开来源**：政府招投标中标公告（必须公示单价）· 海关 HS 编码单价 · 上市公司财报与招股书 · 二手设备拍卖与破产清算（产能的真实价值信号）· 设备商 B2B 挂牌价（口径弱但给量级）。

**不同口径不能混比**，每条注明是零售、B2B 挂牌、中标、海关还是财报推算。

**成本要早派，它是筛选器不是补充。**

### 信源先看 resources.md

阶段一攒下的 `resources.md` 是这个行业的信息地图——期刊、协会、展会、数据入口。**写任务书时先翻它**，把具体的检索入口写进任务书，比让 subagent 从零找信源命中率高得多。

本轮发现的新信源**回写进 resources.md**，它跨阶段累积。

## ③ 派队

后端自选（codex / 内置并行 agent 均可）。**投多路之前先跑一路探针**，确认所选后端在非交互模式下真的能联网。

### 任务书四要素

每个 subagent 需要：**目标 · 输出格式 · 用什么工具和信源 · 清晰的任务边界**。

边界是防重叠的关键——含糊指令会导致两路跑同样的搜索，而真正的子问题没人覆盖。

## 铁律（违反即作废）

## 工作方式（强制）

1. **第一步就先创建输出文件并写入章节骨架。**
2. **每完成一个子问题就立刻追加写入**，不要等全部查完再写。
3. 单个子问题检索上限 8 次，查不到写"未能确证"进入下一个。
4. 全程预算 30-40 次，用完即收尾。
5. **最近两次检索返回相似信息就立即停止**这一子问题。

## ④ 核完整性

1. **每一路的退出码、输出文件大小、来源表行数**。退出码为 0 但文件为空的要重派——**以输出文件的增长判存活，不看退出码**（见 traps）
2. **跑引用校验**，非零退出就打回该路：

   ```bash
   python3 ~/.claude/skills/tech-scout/assets/sources.py \
     --ledger rounds/NN/sources.json verify rounds/NN/raw/*.md
   ```

   它会抓出**账本里不存在的引用**（疑似编造）。加 `--require-quotes` 可进一步要求每个被引用的来源都挂过逐字引文。
3. **交叉核对**：不同路引用同一条来源而归类或表述不一致的，**回原文核**。注意看正文而不是只看摘要——上一个项目抓到的那次引用错误，出错的是摘要建议行，该路正文写对了
4. **冲突证据**：全行业没解决，靠流程不靠模型。**强制标注分歧，不要自行调和**

⚠️ **不要做只看草稿的 fact-checker。** 拿拼好的正文让模型挑内部矛盾、不重新检索、不与来源交叉核对——这种做法结构上抓不到"读起来很顺的自信编造"，而那正是要防的东西。

⚠️ **来源可信度靠人不靠自动评测。** 有团队记过：agent **偏好 SEO 内容农场胜过权威一手来源**，这个问题是人类测试者发现的，自动评测完全没抓到。

## ⑤ 写 digest + 更新地图

`digest.html` 的写法见 [`digest.md`](digest.md)。

同时更新：

- `unknowns.md` —— 已答的转状态，新暴露的进第四象限
- `glossary.md` —— 本轮引入的新术语
- `STATE.md` —— 阶段、下一步、本轮结论要点、**新推翻的说法**

### 变更级联（最容易漏的账）

交付链是有方向的：`unknowns → plan → raw → digest → 结论/建议`。

**改了上游的任何一环，下游全部节点必须增量更新，跳过中间节点是禁止的。**

| 变更类型 | 触发到哪一级 |
|---|---|
| 只改表述 | digest |
| 补数据 | raw → digest → 结论 |
| 调结论 | digest → 结论 |
| 改方向 | unknowns → plan → 全部 |

具体到我们：**补了一路调研 → 技术清单某一行变了 → "只做三件事"的推荐要不要跟着变。**

## ⑦ grill（本流程独有）

用户读完 digest 之后，**再拷问一次**。两个目的：

1. **他理解了没** —— 不是考试。用"这条对你意味着什么""如果换成 X 你会怎么判断"这类问题带出来。答得上来的术语在 glossary 里晋级到「已掌握」
2. **新知识长出了什么新方向** —— 第四象限（unknown unknowns）只有在他读完新东西之后才会冒头。**这是整套流程存在的理由，不要省**

拷问完更新 `unknowns.md`，下一轮的任务书从更新后的地图长出来。

## ⑧ 判断续否

三条一起看：

**1. GAO 三选一**

| 判决 | 含义 |
|---|---|
| **充分** | 证据的保真度、环境、充分性、可接受性均达标，**无需进一步取证** |
| **不足** | 信息不足以做出可信、客观、可靠的判断，**回去补** |
| **拒绝定级** | 因保真度不足或结果不确定，**拒绝给结论** |

第三种是合法输出。硬给一个没证据支撑的结论比说"定不了"更糟。

**2. 仪表化指标**

- 本轮**新增去重后证据条数**
- 本轮查询与前几轮的**相似度**
- 各路充分性条件的**达成率**

**3. 剩余空白五分类** —— 只有第一类值得再派：

| | 例子 | 转成什么 |
|---|---|---|
| ✅ 文献可答 | 机理、参数谱、标准、专利地图 | 下一轮 |
| 🔬 只能做实验 | 交互作用、自家工序的损失 | 实验清单，按「价值÷成本」排序 |
| ✉️ 只能发询价 | 真实报价、MOQ、交期、样品 | 询价清单 |
| 💰 只能付费取档 | 官方登记簿、审查档案 | 付费清单 |
| ⚖️ 只能找律师 | claim chart、逐国 FTO | 外部资源 |

**反向检验**（借自系统综述方法学）：删掉某个检索词若会漏掉相关记录 → **不能停**；若只检出公认关键文献、引文追踪翻不出新东西 → 那是"偏向已知研究"的**危险信号，不是充分信号**。

**完成判据**：你判断够了 **且** 用户明确同意。

### 交接提示词（原样输出给用户，路径替换成真实路径）

## 专利那一列的三个坑

**过期的是那一份权利要求，不是整个方向。** 具体的新增配方、装置、结构和产品权利仍可能被后续专利覆盖。

- **母案放弃 ≠ 续案失效。** continuation 是独立的，不能跟着母案一起判死
- **聚合数据库的状态标注有滞后与误标。** 关键件要交叉验证第二来源，并注明验证到什么程度
- **生产地的专利状态比来源国更重要。** 在哪生产就先查哪国的同族

**逐国 FTO 与 claim chart 超出调研能力边界。** 标为需外部法律资源，不出法律意见。也不要写"该专利已全部过期"这种全称判断。
